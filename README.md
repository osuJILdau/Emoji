# Emoji Finder

Вёрстка страницы по макету Figma на React и TypeScript.

## Использовано

- Vite
- React + TypeScript
- CSS Flexbox и Grid
- шрифт Inter
- Oxlint

## Запуск

```bash
npm install
npm run dev
```

Открыть адрес, который появится в терминале (обычно http://localhost:5173).

## Проверка проекта

```bash
npm run build
npm run lint
```

Поиск работает по названию и ключевым словам в трёх карточках из макета.

Макет: https://www.figma.com/design/HCciSRJI0qWzJwNoK6mb4b/Проекты-React?node-id=9249-18
